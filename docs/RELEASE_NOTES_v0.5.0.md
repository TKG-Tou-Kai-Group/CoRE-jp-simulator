# CoRE Simulator v0.5.0 (案)

オートアタッカーを追加しました。大会ルールで「プログラムで動く自律機」が遊べます。

## 新しいこと

- **オートアタッカー** (HP 200、ミニディスク 200 枚、完全自律、各同盟 1 台まで)。動きは「条件 → 行動」の行を
  上から順に評価するプログラムで決まります (カルネージハートや Gladiabots と同じ考え方)。設定画面とロビーの
  「オートアタッカーのプログラムを編集」で、ボタンを押して条件・値・行動・狙いを選びます
  - 条件: いつでも / 敵が N m 以内 / N m 以内に敵なし / HP が N % 未満 / 残弾が N 枚未満 / 開始から N 秒以上・未満 /
    相手陣地を攻撃できる / 味方が N m 以内 (1 行に 3 つまで、AND)
  - 行動: 敵に近づいて撃つ (間合い N m) / 相手陣地を攻撃 / 地点へ移動 (中央、自陣地の前、相手陣地の前、スタートゾーン、左右の通路、相手のスタートゾーンの前) / その場で待機して撃つ / スタートゾーンへ戻る。
    狙いは いちばん近い敵 / HP が少ない敵 / ヘッド優先 / ビルダー優先 / ビルダー以外
- 試合中に人がすることはありません。ラウンド開始 2 秒後に自動で始動します (ルールの始動・停止の命令は安全手順なので省きました)
- 設定に「各同盟のオートアタッカー (0 / 1 台)」と「自分: オートアタッカー」を追加。自分がオートアタッカーのときは、
  自分のプログラムで動く機体を一人称で観戦しながら、総大将としてスキルと始動・停止を出します
- ネット対戦では各参加者のプログラムをロビーでホストへ送り、ホストが実行します。ロビーでもオートアタッカーの数を選べます
- 通信プロトコルを v6 に (ミニディスク、オートアタッカーの状態、プログラム)。v0.4 とは接続できません

## 既知の問題・割り切り

- オートアタッカーの映像を総大将の画面の小窓に出す機能はまだありません
- 「地点へ移動」は名前付きの 7 点のほか、「地図」ボタンで真上からの絵をクリックして任意の点を選べます (青同盟では点対称に写します)
