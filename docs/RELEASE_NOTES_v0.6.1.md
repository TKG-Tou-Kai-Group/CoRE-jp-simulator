# v0.6.1

## ゲームパッドの割り当てを見直し

右スティックで旋回しながら □ で撃つのは指が足りないので、以前の並びに戻しました。

| 操作 | v0.6.0 | v0.6.1 |
|---|---|---|
| 発射 / つかむ・放す | R1 / R2 / × | **R1 / R2** |
| ターボ | L1 / L2 | **L2** |
| 地図 (俯瞰) の表示切替 | △ | **L1** |
| スキルを選ぶ / 発動 | 十字← → / □ | 十字← → / □ (変更なし) |
| ハンド上下 | 十字↑↓ | 十字↑↓ (変更なし) |

タブレットの仮想パッドも同じ割り当てになります (見た目は変わりません)。

## 操作の割り当てを変えられるように

くわしい設定 → 「操作の割り当てを変える」で、操作ごとにキーボードのキー 2 つとゲームパッドのボタン 2 つを
好きに入れ替えられます。枠を押してからキーかボタンを押すと決まり、Esc で取り消し、Delete でキーを空にできます。
「既定に戻す」で元に戻ります。設定は端末に保存され、次回起動時も有効です。

固定のまま: 左右スティック (移動・旋回・ビルダーのハンド)、スキルの番号キー 1〜9、ストライダーの Q W O P。
