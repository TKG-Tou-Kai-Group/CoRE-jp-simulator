# オートアタッカーとストライダーの設計メモ (v0.5 に向けて)

## オートアタッカー

### ルール上の位置づけ (CoRE-1 V27.1.3)

- 完全自律。人はラウンド開始後に「始動」、緊急時に「停止」の命令を送るだけ (12.7)。停止したら再始動できない
- HP 200、撃破から 30 秒で復活 (3 分まで)。ヘッドアタッカーにはなれない (6.3 / 6.6 / 10.6)
- ミニディスク (直径 100 mm) を 200 枚、セッティングタイム中に積む。ラウンド中の補給は禁止 (8.4)。
  手動補給エリアに入ると反則 (9.1)。1 命中 10 ダメージ (6.4)
- 各同盟 1 台まで。アタッカー + ビルダーの 4 台 (決勝 5 台) とは別枠 (10.6)
- ラウンド中、オートアタッカーの映像は総大将に届く (8.4)

### プログラム

カルネージハート (OKE のチップ) と Gladiabots (条件 → 行動の優先リスト) に倣い、**上から順に評価する「条件 → 行動」の行**
にする。Scratch のようなループや変数は持たない。1 行 = 1 ルール、最大 12 行、条件は 1 行に 3 つまで (AND)。

| 条件 | 書き方 | 意味 |
|---|---|---|
| いつでも | `always` | 常に成り立つ |
| 敵が近い | `enemy<N` | いちばん近い敵が N m 以内 |
| 敵がいない | `enemy>N` | N m 以内に敵がいない |
| HP | `hp<N` | 自機の HP が N % 未満 |
| 残弾 | `ammo<N` | 残弾が N 枚未満 |
| 時間 | `time>N` / `time<N` | ラウンド開始から N 秒以上 / 未満 |
| 陣地 | `base` | 相手の陣地を攻撃できる (3 分経過、未撃破) |
| 味方 | `ally<N` | いちばん近い味方が N m 以内 |

| 行動 | 書き方 | 意味 |
|---|---|---|
| 交戦 | `engage=R` | 相手に近づいて撃つ。間合い R m を保つ |
| 陣地攻撃 | `base` | 相手の陣地のパネルを撃つ (攻撃できない時間は交戦) |
| 移動 | `goto=center / ownfront / enemyfront / start / left / right / enemystart` | 名前付きの地点へ。撃たない。着いたら止まる (撃つなら上の行に「敵が N m 以内」で交戦や待機を書く)。right = 自分のブロックゾーン側の通路 (赤なら (-3, -3))、left = 相手のブロックゾーン側の通路 (赤なら (3, 3)、自陣地の前と離すため中央より向こう) |
| 待機 | `hold` | その場で止まり、射程内の相手を撃つ |
| 退避 | `retreat` | 自同盟のスタートゾーンへ戻る |

狙いの選び方 `@nearest / @weakest / @head / @builder / @attacker` を行動に付けられる。

既定のプログラム:

```
ammo<1 > retreat
hp<30 > engage=8 @nearest
base & enemy>6 > base
enemy<12 > engage=5 @nearest
always > goto=center
```

実装は純 C# の `CoreSim.Rules.AutoProgram` (解析・整形・評価、単体テストあり)。ゲーム側の `AutoAttackerSource` が
毎回センサー値 (敵・味方までの距離、HP %、残弾、時間、陣地攻撃の可否) を埋めて行を選び、`BotCommandSource` に
指示 (Directive) として渡す。移動・経路・照準・発射は CPU アタッカーと同じ部品。

### 画面

- 設定画面とロビーから「オートアタッカーのプログラム」を開く。行ごとに [条件][値][+条件] → [行動][値][狙い] と
  [↑][↓][×] のボタン。値はボタンで候補を巡回する (ドロップダウン無し。タブレットでも作れる)
- 「地点へ移動」の地点は、真上からのフィールドの絵の上の印からも選べる (`MapPickerView`)。選べるのは名前付きの
  地点だけで、ルールに詳しくなくても場所を直感的に選べるようにするためのもの。絵は自同盟が左になる向き
- 試合中に人がすることは無い。ラウンド開始 2 秒後に全同盟で自動始動する (ルールの始動・停止の命令は安全手順なので
  ゲームでは省く。ルールのモデル `TournamentRound.StartAuto / StopAuto` は残してある)
- 総大将への映像 (8.4) はゲームでは作らない。プレイヤーは機体の操縦者であって総大将ではないため

### 保存とオート対戦

- プログラムは名前を付けて 8 つのスロットに保存できる (`ProgramSlotsView`、PlayerPrefs に JSON)。読み込むと編集中の
  プログラムに置き換わる。ネット対戦のロビーで読み込めば、そのプログラムがホストへ送られる
- かんたんルールの「オート対戦」は、自分のプログラムのオートアタッカーと、設定で選んだスロットのプログラムの
  オートアタッカーを 1 対 1 で戦わせて見るだけのモード (カルネージハート風)。相手のスロットが空なら既定のプログラム
- 設定「CPU のプログラム」を選ぶと、オート対戦の相手と CPU のオートアタッカーだけでなく、普通の CPU アタッカー
  (ヘッド含む、かんたんルールの CPU も、ホストの CPU も) が同じプログラムで動く (`AutoAttackerSource.DrivesAttacker`)。
  弾切れのピットイン申請と補給は CPU のままで、動きだけプログラムに従う。保存したプログラムを CPU に持たせることで
  難易度を自分で調整できる。既定 (内蔵の CPU) は今までどおり

### ネット対戦

- プログラムはテキストでホストへ送る (`Program` メッセージ、2000 文字まで)。ホストが実行する (ホスト権威のまま)
- ロビーで各同盟のオートアタッカーの数 (0 / 1) を選ぶ。スロットの種別は番号順に ヘッド → アタッカー → ビルダー → オート
- CPU のオートアタッカーは既定のプログラムで動く

## ストライダー (v0.5: 単独のタイムアタック)

実装:

- `Strider` (StriderFactory.cs): ArticulationBody で胴体 → 股関節 (ピッチ) → 膝 (ピッチ) を 4 本。腿・脛とも 0.22 m
  (15.3 の 200〜400 mm)、胴体 6 kg。関節はサーボ (ArticulationDrive: stiffness 2000、damping 100、上限 150 N·m) で目標角を
  追従。直立は腿 25 度・膝 50 度で脚先が股関節の真下、胴体の高さ 0.40 m。股関節の幅 0.30 m、脚は 10 度外へ開く。
  脚にピッチしか無いので (実機は外転で踏ん張る)、ロールを戻す補助トルク (80 N·m/rad) と、進行方向へ向け直す補助トルク
  (60 N·m/rad。左右の脚を別々に動かせないので向きを直せず、歩くうちに回ってコースから出た)、胴体を水平に戻す弱い補助
  トルク (25 N·m/rad) を胴体に掛ける。`RollAssist` / `YawAssist` / `PitchAssist` を 0 で無効。
  胴体の長さは股関節の間 0.50 m (ハードル 30 cm を越えるとき前後の脚が同時に引っ掛からないように)、腿は前へ 90 度、
  膝は 160 度まで畳める
- `StriderChallenge`: 赤サイドのストライダーエリアで遊ぶ単独モード。Q / W = 対角ペア A の腿を前 / 後ろ (B は逆)、
  O / P = ペア A の膝を曲げる / 伸ばす (B は逆)。キーを押している間だけ目標角が動き、離すと保持する (QWOP より扱いやすい)。
  矢印で視点をロボット中心に回す。R でやり直し、Esc でメニュー
- 踏破の判定は純 C# の `StriderCourse` (7.7: 脚先が線を越えたら踏破、順に、得点は 1 回だけ。線の位置はモデルの白線)。
  テストあり。砂利ゾーンは滑りやすい床と小石で代用。エリア外に接地すると警告 (大会では反則)
- 階段ゾーンの台はモデルのまま (ゴール側から登る形で、踏破はその脇を通る)

元の方針:

- 4 本脚、脚は 2〜3 自由度、ストライダーエリア (24 m × 1.5 m) の 7 つのゾーンを踏破 (3.8 / 7.7 / 第 15 章)。
  脚 1 本が線をまたげばゾーン踏破で +10 VP (RP 40 / 60)、全踏破 +40 VP。HP なし。エリアの障害物メッシュは
  フィールドのモデルに入っている (`strider_obst`)
- 操作は QWOP 方式: 脚を対角のペアで結び (トロット)、前脚ペアの腿・脛、後脚ペアの腿・脛の 4 キー。
  奥行きが分かりにくいので 2D の横視点に固定せず、十字キーでロボット中心に視点を回して好きな角度から見ながら歩かせる
- 補助として歩容のひな型 (片方のペアを自動で周期運動) を選べるようにし、慣れたら外す
- 脚の寸法や関節の配置はオープンソースの 4 足歩行ロボット **MEVIUS** (東大 JSK) を参考にする
- 関節は ArticulationBody か HingeJoint のモーターで目標角を追従。最初は大会ルールから切り離したタイムアタックの
  単独モードとして作り、面白さが確認できてから同盟の VP に組み込む
