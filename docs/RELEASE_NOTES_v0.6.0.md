# CoRE Simulator v0.6.0

初めて触る人のための導線を整えました。CoRE やこのゲームを知らなくても、何をするゲームか・自分がどの機体で何を
すれば得点かが分かるようにしています。

## ダウンロード

| OS | ファイル | 起動 |
|---|---|---|
| Windows 10 / 11 (64 bit) | `CoRE-jp-simulator_v0.6.0_Windows_amd64.zip` | 展開して `CoRE Simulator.exe` を実行 |
| Linux (x86_64) | `CoRE-jp-simulator_v0.6.0_Linux_amd64.zip` | 展開して `./CoRE-jp-simulator.x86_64` を実行 (必要なら `chmod +x`) |

## 新しいこと

- **はじめに**: 初回起動時に CoRE とこのゲームの説明を短く出します。「CoRE について」で詳しい説明と公式サイトの QR コード
- **タイトルの作り直し**: 「撃ち合う」「大会の試合に出る」「4 本脚を歩かせる」のカードから選びます。細かい数値は「くわしい設定」へ
- **あなたの機体**: 大会の試合はアタッカー / ビルダー / オートアタッカーのカードから選びます。できること・得点・操作を 1 行ずつ
- **手ほどき (チュートリアル)**: アタッカー (11 手順) とビルダー (9 手順) は、黄色い印と床の線で道を示しながら
  「撃つ → 補給する → 陣地を撃つ」「運ぶ → 置く → 積む」を実際にやって覚えます。ストライダーは最初の 4 手順を画面で案内。
  いつでも飛ばせます
- **プレイ中のガイド**: 試合前の 1 枚 (あなたの機体・目標・操作)、画面上の「今の目標」(状況で変わる)、初めて撃破された /
  弾切れ / 陣地攻撃の解禁のときのヒント、結果画面の内訳と「次に試すこと」。H キーかパッドの Select でいつでも ON / OFF
- **見た目**: ボタンとカードを角丸に。文字の大きさと枠を見直し
- **タブレット + パッド**: カードや手順の板はパッドの十字キーと A でも進められます

## 直したこと

- 機体の番号札が壁や構造物を透けて見え、相手の位置が分かってしまっていた (深度を見る文字シェーダに変更)
