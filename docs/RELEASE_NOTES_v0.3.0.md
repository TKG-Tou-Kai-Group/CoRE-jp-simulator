# CoRE Simulator v0.3.0

CoRE (Championship of Robotics Engineers) の撃ち合いを、ROS 2 も Docker も無しに
実行ファイル 1 つで体験できるシミュレータの最初のリリースです。
CoRE をまだ知らない人が「ダウンロードして 1 分で撃ち合いを始められる」ことを目標にしています。

## ダウンロード

| OS | ファイル | 起動 |
|---|---|---|
| Windows 10 / 11 (64 bit) | `CoRE-jp-simulator_v0.3.0_Windows_amd64.zip` | 展開して `CoRE Simulator.exe` を実行 |
| Linux (x86_64) | `CoRE-jp-simulator_v0.3.0_Linux_amd64.zip` | 展開して `./CoRE-jp-simulator.x86_64` を実行 (必要なら `chmod +x`) |

Windows で「WindowsによってPCが保護されました」と出た場合は「詳細情報」→「実行」で起動できます (署名していないため)。
Android タブレット向けはタッチ操作まで作ってありますが、今回のリリースには含めていません。

## できること

- **かんたんルール**: 装甲板にディスクが当たるたびに HP が 10 減り (初期 200)、時間切れで HP が多い側の勝ち。
  ひとりで対戦 (CPU 1〜3 台)、チーム戦 (2 vs 2)、ふたりで対戦 (画面分割、ゲームパッド 2 台)、練習 (時間無制限)
- **大会ルール**: CoRE-1 ルールブック V27.1.3 (2027 シーズン) 準拠、アタッカーのみ。
  赤同盟 vs 青同盟、1 ラウンド 7 分で VP 500 に達したら終了。撃破 +10VP、陣地撃破 +100VP (開始 3 分後から有効)、
  ヘッドアタッカー (HP 300、毎秒 5 回復) の減った HP が VP に。RP でスキル (ブースト・バリア・ヒーリング・リジェネ・
  ピットイン・サプライ) を発動し、残弾が尽きたらピットインを発動して補給エリアへ。予選 / 準決勝 (2 本先取) / 決勝 (3 本先取)
- **フィールド**: CoRE-1 2027 フィールド (24m × 15m)。公式ルールナビの 3D モデルから変換
- **視点**: 大会と同じく機体に付いたカメラ (一人称) だけ。俯瞰は左下の地図 (V キーで表示切替)
- **CPU**: NavMesh の経路探索で高台やバンカーを回り、弾切れになると総大将 AI がピットインを発動して補給に向かう
- **ネット対戦**: 最大 8 人。同じ LAN なら部屋を自動検索、閉域網ではホストの IP を入力。
  Secure Share Net のような中継サーバー型なら公開アドレスを `dummy.io:9999` の形で
  そのまま入力できます (手順は README の「ネット対戦」)。
  通信は UDP か TCP のポート 1 つ (既定 7777) だけ。合言葉を付けられる

## 操作

| 操作 | キーボード | ゲームパッド |
|---|---|---|
| 移動 (前後左右) | 矢印 / W S | 左スティック |
| 旋回 | A / D | 右スティック |
| 発射 | Space | RB / RT / A |
| ターボ | Shift | LB / LT |
| 地図 (俯瞰) の表示切替 | V | Y |
| スキル (大会ルール) | 1〜9 | 十字キー左右で選び X (□) で発動 |
| メニュー | Esc | Start |

機体の速さは既定が「ゲーム」(実機の 2 倍) です。実機相当 (0.5 m/s、ターボ 1.0 m/s) にしたいときは設定で「リアル」を選んでください。

## 実機・ルールとの違い (知っておいてほしいこと)

- モデル化しているのはアタッカーだけです。ビルダー、オートアタッカー、ストライダー、コンテナ、ブロックは出てきません。
  そのため VP の内訳は実際の試合より低めになります
- 1 試合 (1〜5 ラウンド) までを再現しています。予選の総当たりや決勝トーナメントの進行はありません
- 射出速度は全ルールで 15 m/s (ルールブック 14.3 の上限) です。ディスクはどこかに触れた時点で消えます
- 弾倉の枚数 (既定 50 枚) はルールブックに無い値です。設定で変えられます
- ダメージパネルの命中検知の条件は無視し、どんな接触でも命中とします
- 牽引による復活、転倒時の非常停止、総大将を操縦者と別にすることは未実装です
- 反則は「進入禁止ゾーン」「ピットイン未発動での補給エリア進入」「相手の補給エリアへの進入」の 3 つだけ判定します

対応表と、再現できていない点の一覧は [docs/TOURNAMENT_RULES.md](TOURNAMENT_RULES.md) にあります。

## 既知の問題

- ネット対戦は通信を暗号化していません。会場の共有ネットワークでは合言葉を付けてください
  ([docs/SECURITY.md](SECURITY.md))
- CPU は構造物の角に引っ掛かることがあります (1.5 秒動けないと後退して向きを変えます)
- 日本語フォントは OS のものを使います。日本語フォントが無い環境では文字が □ になります
- タイトル画面と設定画面のスクロールはマウスとタッチのみで、ゲームパッドでは動きません
