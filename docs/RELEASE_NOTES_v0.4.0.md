# CoRE Simulator v0.4.0 (案)

ビルダーを追加しました。大会ルールで「コンテナの運搬」と「ブロックの建設」が遊べます。

## ダウンロード

| OS | ファイル | 起動 |
|---|---|---|
| Windows 10 / 11 (64 bit) | `CoRE-jp-simulator_v0.4.0_Windows_amd64.zip` | 展開して `CoRE Simulator.exe` を実行 |
| Linux (x86_64) | `CoRE-jp-simulator_v0.4.0_Linux_amd64.zip` | 展開して `./CoRE-jp-simulator.x86_64` を実行 (必要なら `chmod +x`) |

## 新しいこと

- **ビルダー** (HP 80、射出なし)。前方の昇降ハンド (小型のトップリフター) でブロックとコンテナを 1 つ持てます。
  Space (RB) でつかむ / 放す、R / F (右スティック上下、十字キー上下) でハンドの上げ下げ。放したとき近くに
  置き場所があれば揃えて置きます。画面中央下に「何をつかめるか / どこに置けるか / 反則になるか」を表示します
- **コンテナとスポット** (ルールブック 3.3 / 3.4 / 7.1)。置き場 A (4 個)、B・C (5 個ずつ)、共通 (黄 4 個)。
  自同盟のスポット (6 列 × 3 段) に置くと +10VP +30RP、1 つの段に 4 個並ぶと +50VP +100RP
- **ブロックとビルドサイト** (3.5 / 7.2 / 7.3)。各サイド 12 個 + 高台の谷部 2 個。ビルドサイトに 2 個積むと獲得:
  1 = ビルダーの防御力 2 倍、2 = 陣地の防御力 1.5 倍、3 / 4 = 置き場 B / C のコンテナを回収できる。
  陣地の防御ポート、高台の谷部、ブロックキャリアーの上にも置けます。ブロックはディスクを止めます
- **反則** を 6 つ追加 (相手の置き場のコンテナ、スポットからの取り出し、相手のスポットへの設置、
  サイト 3・4 獲得前の B・C 回収、ビルダー以外のブロック保持、ビルドサイトからの取り出し)
- **CPU のビルダー**。サイト 1 → コンテナ → サイト 3・4 → B・C → サイト 2 → 防御ポート の順に運びます
- 設定に「各同盟のビルダー」(0〜2 台) と「自分: ヘッドアタッカー / アタッカー / ビルダー」を追加。
  ネット対戦のロビーでもビルダーの数を選べ、各スロットの種別を表示します (番号の大きい側からビルダー)
- 転倒しても 1 秒後にゆっくり起き上がります (重心も低くしました)
- ネット対戦でホストが「もう一度」を押したとき、参加者側が結果画面のまま固まる不具合を直しました
- F9 で CPU の判断と経路を表示できます (調整用)
- 通信プロトコルを v5 に (ブロック・コンテナの位置、ハンドの高さ、持ち物、試合番号を同期)。v0.3 とは接続できません

## 既知の問題・割り切り

- スポットの四角柱への差し込みは判定しません。番号 1 や「左」の向きはスタートゾーン側と仮定しています
  (詳細は docs/TOURNAMENT_RULES.md)
- ブロックキャリアーは動かない台です (牽引機構が無い)
- CPU は谷部にブロックが 2 個以上あるときだけ高台を渡る経路を持ちますが、陣地とスポットの間を通る道を優先します
- CPU のビルダーは構造物の角で詰まることがあります (2 秒動けないと後退します)
- ビルダーのマストは開始時の大きさ制限 (高さ 1000 mm) を超えています (1.11 m)
