# CoRE Simulator v0.3.1

v0.3.0 からの小さな修正版です。中継サーバー型のネットワーク (Secure Share Net など) 越しに
参加できるようにしました。ルールや操作に変更はありません。

## ダウンロード

| OS | ファイル | 起動 |
|---|---|---|
| Windows 10 / 11 (64 bit) | `CoRE-jp-simulator_v0.3.1_Windows_amd64.zip` | 展開して `CoRE Simulator.exe` を実行 |
| Linux (x86_64) | `CoRE-jp-simulator_v0.3.1_Linux_amd64.zip` | 展開して `./CoRE-jp-simulator.x86_64` を実行 (必要なら `chmod +x`) |

Windows で「WindowsによってPCが保護されました」と出た場合は「詳細情報」→「実行」で起動できます (署名していないため)。

## 変更点

- **「ホストの IP アドレス」欄で `アドレス:ポート` を受け付けるように**。Secure Share Net などの
  中継サーバーが発行する公開アドレス (例 `dummy.io:9999`) をそのまま貼り付けて参加できます。
  この形式で入力したときは、欄のポート番号ではなく公開アドレスのポートが使われます
- **ホスト名の解決で IPv4 を優先**。DNS が IPv6 を先に返す環境で参加に失敗していました
- ネット対戦メニューの説明文と README に、Secure Share Net 経由の手順を追加
  (ゲームと同じプロトコルで公開、Web 認証は「使用しない」、まず TCP で試す)

## Secure Share Net で遊ぶときの手順

1. ホストはゲームで「部屋を作る」(例: ポート 7777、方式 TCP)
2. ホスト PC で Secure Share Net ツールを起動し、ローカルポート 7777、プロトコルをゲームと同じにして公開。Web 認証は「使用しない」
3. 公開アドレス (例 `dummy.io:9999`) を参加者に伝える
4. 参加者は「ホストの IP アドレス」欄に公開アドレスをポート込みで入力し、通信方式をホストと同じにして「参加する」

「同じ LAN 内の部屋」のリストには出ません (LAN 内のブロードキャストで探しているため)。
「参加する」ボタンで入ってください。

## 既知の問題

- UDP で公開した場合、中継サーバーが参加者ごとに送信元ポートを分けないと 2 人目以降が入れないことがあります。
  その場合は TCP に切り替えてください
- v0.3.0 の既知の問題 ([RELEASE_NOTES_v0.3.0.md](RELEASE_NOTES_v0.3.0.md)) はそのままです
